DEVICE X PRO PLUS
=================
This build adds:
- Category selector: All devices, Smartphones, Laptops, Tablets, Desktop PCs, Smartwatches.
- Visible device type label on every card and in the details window.
- Product image area on each card. It tries to find an image through Wikimedia Commons when a card appears. Some exact models may have no suitable image; the card then shows a category symbol instead.
- Search, brand filter, sorting, details modal, load-more pagination, mobile layout.

To update GitHub Pages:
1. Extract this ZIP.
2. Upload index.html, styles.css, app.js, README.txt directly into the root of your DEVICE_X repository.
3. Replace the old files and commit to main.
4. Wait for Pages deployment, then refresh the same public URL.

Data note:
Public datasets currently provide phone and laptop rows. Tablets, desktop PCs and smartwatches are represented by a small clearly limited starter set in this version; they are not an exhaustive database. Specifications are not manufacturer-certified and may vary by configuration. Wikimedia image results are not guaranteed to match every exact device. The app needs internet for remote datasets, fonts and image lookup.
